# v0.7 content pack vs the live_updated site

**6 November 2026.** Compared: `Quadra_Website_Review_Pack_v0.7_2026-11-06 (1).zip` (`content.json`, 77 pages) against the
built site in `live_updated/` (what runs on localhost:8081 and on staging, main @ 5826a42).

**Method.** Every text field of every v0.7 page (2,356 items) was matched against the visible text of its built page.
The 547 items not found word for word were checked one by one by four sub-agents (Microsoft & Azure · Modern Work &
Security · AWS & Google Cloud · all other pages), each sorting them into *present* (same words, different layout),
*reworded*, *missing* or *not page text* (review notes, SHA hashes, link targets), and spot-checking items that did
match. The main findings were then re-checked directly in the built HTML.
