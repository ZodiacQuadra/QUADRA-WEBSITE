# v0.6 content pack vs the live_updated site

**Scope:** the Home page and the Solutions, Technology Practices and Why Quadra menus (67 pages in v0.6), compared
with the built site in `live_updated/` (localhost:8081). Only the v0.6 pack is used; v0.7 is left out.

**Method:** all 1,839 text items of those v0.6 pages were matched against the visible text of each built page, and each
built page's text was matched back against v0.6 to find extra content. Three sub-agents (Home/Solutions/Why Quadra ·
Microsoft · other Technology pages) then checked every flagged item by hand, and the main findings were re-checked in
the built HTML.
